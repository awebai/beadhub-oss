# Public-site provenance

The deployable Hugo source in this directory was recovered on 2026-08-23 from:

- repository: `https://github.com/juanre/beadhub.ai`
- source commit: `7b1f291539c0230106db2a339372a85d9c410896`
- source branches at recovery: `main` and `deploy`

The import intentionally includes only deployable site inputs: `archetypes/`,
`content/`, `layouts/`, `static/`, `Makefile`, `hugo.toml`, `package.json`, and
`pnpm-lock.yaml`.

Generated `public/` output, internal launch/outreach notes, coordination
databases, agent configuration, conversation transcripts, and repository
instructions were not imported.
Those are operational history, not public-site source, and some are unsuitable
for a public repository.

`awebai/beadhub-oss/site` is authoritative from this point forward. The legacy
repository preserves its full history and remains a deployment mirror until
Juan performs the Render change; it is not a second development authority.
